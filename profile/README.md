# Examen Silentii (ExSil)

**An open journal of independent, reproducible examinations of scientific software and public research data.**

ExSil publishes reports that test whether a widely used or consequential tool or dataset produces correct results, whether it signals when it does not, and how its maintainers responded.

- **Website:** https://examen-silentii.github.io
- **Submissions and open review:** [examen-silentii/submissions](https://github.com/examen-silentii/submissions)
- **Article template:** [examen-silentii/article-template](https://github.com/examen-silentii/article-template)
- **Archive:** [Zenodo community](https://zenodo.org/communities/examen-silentii)

Free to submit, free to publish, free to read.
